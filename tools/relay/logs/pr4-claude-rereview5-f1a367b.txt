- **Flags:** they are parsed as hex with `0x` optional. `flags_admin_up` tests only IFF_UP. `flags_capture_ok` tests UP, PROMISC and NOARP. Nothing tests LOWER_UP. `eno1_link_ok` needs speed 10000, admin-up, and carrier=1 or oper=up.
- **Signals:** `trap '' HUP PIPE` is set at line 320.
- **Nonzero exit reverts:** `set -E` plus the ERR trap sets `failed`, and the EXIT trap checks `rc != 0`. Revert runs only when `revert_ready` and `this_run_changed` are both set. Otherwise it prints `CONFIG-KEPT`.
